ACTIVIDAD 11 NIVEL: PRACTITIONER PLATAFORMA: PORTSWIGGER

01 // Ficha Técnica del Laboratorio

Nombre del Laboratorio:File path traversal, traversal sequences stripped with superfluous URL-decode

Clasificación OWASP: A01:2021 – Broken Access Control

Técnica Utilizada: Prefix Retention Traversal (Mantenimiento del prefijo requerido)

Objetivo Técnico: Cumplir con la condición del servidor de incluir la carpeta de origen requerida (/var/www/images/) y escalar hacia /etc/passwd.

02 // Marco Teórico

Validación de Prefijo Insuficiente: La aplicación valida que el valor ingresado empiece exactamente con la ruta base esperada (ej. /var/www/images/). Sin embargo, al no restringir el uso de ../ inmediatamente después del prefijo, permite salir de dicho directorio base.

03 // Procedimiento de Explotación Paso a Paso

  1. Intercepta en Burp la petición con el valor por defecto: /var/www/images/7.jpg.
  2. Conserva el prefijo exacto e inyecta la secuencia de escape justo después: 
    GET /image?filename=/var/www/images/../../../etc/passwd HTTP/1.1
  3. Envía la petición mediante Repeater. El servidor valida que el string comienza con /var/www/images/ y luego procesa el cruce hacia la raíz.
